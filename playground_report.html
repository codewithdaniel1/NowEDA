2. Task-aware ML guidance¶

With no arguments, NowEDA assesses which ML directions are plausible without silently selecting a target. Supervised tasks require a target; providing one without problem_type transparently infers classification or regression. Set plan=True when code needs the structured result. Its stars and /5 scores are estimated dataset-fit ratings, not measured model performance.

Start with the simplest recommendation call¶

When the objective is unknown, a completely argument-free df.eda.mlall() assesses possible target candidates and unsupervised directions. It does not claim that a likely-looking column is definitely the target.

SECTION 3: The Plugin System (Custom Analysis Workflows)¶

Run specific plugins for lightweight, custom analysis. Useful when you only care about certain checks.

How Plugins Work¶

Accessor reports combine the eight default plugins. You can also run plugins manually for:

  • Lightweight analysis (run only what you need)
  • Custom workflows (combine built-in + your own plugins)
  • Programmatic access to raw results

Available Plugins:

  • SchemaPlugin — Column roles & types
  • StatsPlugin — Descriptive statistics
  • MissingDataPlugin — Missing value rates
  • DuplicatesPlugin — Duplicate rows & constants
  • CorrelationPlugin — Correlation matrix
  • OutlierPlugin — Outlier counts
  • PIIDetectorPlugin — PII findings
  • EncodingDetectionPlugin — Encoding signals

Example 4: Write Your Own Custom Plugin¶

Create a custom plugin to add domain-specific analysis. This example distinguishes identifiers, temporal fields, and high-cardinality text instead of treating every unique value as an ID.

import pandas as pd

from noweda.plugins.base import BasePlugin

class HighCardinalityPlugin(BasePlugin):
    """Review highly unique fields without treating every one as an ID."""
    name = "high_cardinality"

    def run(self, df):
        results = {}
        for col in df.columns:
            unique_ratio = df[col].nunique() / len(df) if len(df) else 0
            if unique_ratio <= 0.95:
                continue

            name = str(col).lower()
            if pd.api.types.is_numeric_dtype(df[col]):
                if name == 'id' or '_id' in name or name.startswith('id_'):
                    warning = 'Likely identifier — exclude from model features.'
                else:
                    continue  # Continuous numeric values are normally unique.
            else:
                sample = df[col].dropna().astype(str).head(20)
                parsed = pd.to_datetime(sample, errors='coerce', format='mixed')
                if not sample.empty and parsed.notna().mean() >= 0.8:
                    warning = 'Temporal field — parse as datetime and derive temporal features.'
                else:
                    warning = ('High-cardinality text — it may be an identifier, PII, or free text; '
                               'do not encode automatically.')

            results[col] = {'unique_ratio': unique_ratio, 'warning': warning}
        return results

Extended Example: Chunked Ingestion¶

CSV/JSON and all chunked reads use pandas. concat=True retains every chunk and allocates a combined DataFrame, so the full data and concatenation overhead must fit in RAM. concat=False lets you process chunks without retaining them all.

Use contextlib.closing() when iterating: it closes the file reader and loading indicator even if you break early or processing raises an exception. Fully consuming the stream produces the 100% completion indicator.
